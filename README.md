# ToonQuest

A playable JRPG prototype starring the cute toon characters from PicQuad. Built in Godot 4.7.

**Play it here:** https://outerheavenx.github.io/toon-quest/

## The game
- **Party of 4**: Sir Pounce (Kitten Knight, tank), Mochi (Panda Mage), Swift (Raptor Rogue), Clover (Bunny Cleric, healer)
- **Overworld**: explore Toonwood Meadow, tap-to-move, talk to Old Hoot the owl, heal at the crystal, wander into tall grass for random encounters
- **Turn-based battles**: Attack/Skill/Item/Defend/Flee, unique skill per hero, damage numbers, crits, XP & level-ups
- **Enemies**: Grump Slime, Thorn Pup, and a rare King Slime mini-boss

All sprites AI-generated in the PicQuad toon style. All sound effects synthesized in code — no paid assets.

## Prototype status
This is a working prototype. If it clicks, it grows into a full game: towns with shops, a story quest, more heroes, skill trees, real bosses, and a save system.
